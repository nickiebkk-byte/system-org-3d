# FLEXI Organize 3D

เว็บแอปจัดระบบรางติดผนัง FLEXI (Organize System) แบบ 3D และ 2D สำหรับลูกค้า ใช้ธีม BLUE WORKSPACE เดียวกับ "ชั้นวางติดผนัง DIY"
- รางรับชั้น 60 / 90 / 150 ซม. ต่อรวมกันได้ทุกขนาด (60–300 ซม.) สีขาว/ดำ ช่องบนรางทุก 10 ซม. ระยะรางเท่ากับความกว้างแผ่น (60 หรือ 80)
- สินค้า: แผ่นชั้นเมลามีน (ขาว/วอลนัท) · แผ่นชั้นตะแกรง · แผ่นชั้นเรียบ · ตะกร้าตื้น/ลึก · ราวแขวนผ้า 6 เส้น · ราวอะลูมิเนียม · แผงเหล็ก · รางแขวนบน
- คำนวณแขนรับชั้นอัตโนมัติ: รางที่อยู่ระหว่าง 2 ช่องและมีชั้นระดับเดียวกัน → แขนคู่ 1 ตัว · รางริม → แขนเดี่ยว (L,R)
- รายการสินค้าพร้อมรหัส Article รูป และจำนวน · บันทึก PNG / PDF · คัดลอกรายการ
- ของตกแต่งประกอบภาพ (ไม่รวมในรายการสินค้า): ตู้เย็น เครื่องซักผ้า เครื่องซัก+อบซ้อน ต้นไม้ ตะกร้าผ้า กล่องเก็บของ และของบนชั้น เช่น เสื้อผ้าบนราว ผ้าพับ กล่อง หนังสือ รองเท้า
- แบบไอเดีย 22 แบบ (ตู้เสื้อผ้า ห้องซักรีด ห้องเก็บของ) กดใช้แล้วโครงสร้างขึ้นใน 2D/3D แก้ไขต่อได้ · ภาพอยู่ในโฟลเดอร์ `ideas/`
- บันทึกแบบตั้งชื่อได้ · ติดตั้งเป็นแอปบนหน้าจอโฮมได้

## เปิดใช้งานด้วย GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
ลิงก์จะเป็น `https://nickiebkk-byte.github.io/system-org-3d/`

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ข้อมูลสินค้าอยู่ในส่วน `SKU` ด้านบนของสคริปต์) |
| `theme-blue-workspace.css` | ธีมเดียวกับแอปชั้นวางติดผนัง DIY |
| `photos/` | รูปสินค้าจากตาราง SIZE FLEXI |
| `manifest.webmanifest`, `sw.js`, `icons/` | ติดตั้งเป็นแอป และเปิดได้แม้ไม่มีอินเทอร์เน็ตหลังเปิดครั้งแรก |
| `src/` | ไฟล์ต้นฉบับ (body.html + app.js) ใช้ `python3 src/build.py` รวมเป็น index.html |

ถ้าแก้แล้วเครื่องยังเห็นเวอร์ชันเก่า ให้เปลี่ยน `CACHE` ใน `sw.js` เป็นเลขใหม่ (เช่น `-v2`)

## สมมติฐานที่ควรยืนยัน
- แขนเดี่ยว (L,R) นับเป็น "ตัว" แยกซ้าย/ขวา ถ้า 1 รหัสขายเป็นชุดคู่ ให้ปรับการนับ
- แผงเหล็กแขวนบนรางรับชั้นโดยตรง (ไม่ใช้แขน) สูง 40 ซม.
- ตะกร้าใช้แขนรับรางเลื่อน และใส่ได้เฉพาะช่องกว้าง 60
- ราวอะลูมิเนียมยึดใต้แขนรับชั้น เลือกแขนลึก 20/30/40 ได้
